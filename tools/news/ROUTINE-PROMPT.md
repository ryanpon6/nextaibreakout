# Draft routine: "NAB daily Grok Bot news" (text only; not created)

---
Daily NAB news run. Usage-light: do the steps in order, stop the moment one says stop. No chat, no messages to anyone.
Work in the autopost checkout /workspace/nab-autopost (git worktree, branch `autopost` tracking origin/main; publish.py pushes HEAD:main fast-forward only). Before step 1 run: cd /workspace/nab-autopost && git fetch origin && git merge --ff-only origin/main  (if that fails, STOP; it means someone left local changes). D = today's date in America/Edmonton (YYYY-MM-DD). State dir S = /workspace/shared/nab-relaunch/news.

1. X reads (Grok Bot's public X tools, namespace "x"; at most 4 calls):
   - x.search_news query "Grok Bot", max_age_hours 24, news.fields name,summary,updated_at,cluster_posts_results
   - x.search_posts_all query "\"grok bot\" -is:retweet lang:en", start_time = now minus 24h (UTC), sort_order relevancy, max_results 25, post.fields created_at,public_metrics,text,author_id, expansions author_id
   - x.search_news query "Claude", max_age_hours 24 (second priority)
   Group posts into stories. Write S/candidates-D.json: {"date": D, "stories": [{"key", "topic": "grokbot"|"claude", "headline", "news_url" (x.com/i/trending link if any), "post_ids": [...]}]}. Add "x_reads": <number of x.* tool calls you made in this step> (the cost log needs it). Include ids only for real posts you saw. Leave out giveaway / "comment X and I'll DM you" posts and unverified money claims.
2. Run: PYTHONDONTWRITEBYTECODE=1 python3 tools/news/fetch.py --date D --log-trends --x-reads N   (N = your x.* call count from step 1)
   Exit 10 = quiet day (no new X story and no qc-PASS item in S/lessons/): STOP silently. Exit 0 can be an X story or a lesson from the queue; a priority:true lesson is picked ahead of an X story and the X story is not logged as covered, so the next run can pick it if it is still inside the 24h window. Exit 2 = fix the JSON once, rerun; if it still fails, STOP.
3. If fetch.py printed that it picked a lesson, S/spec-D.json is already written from a Quality Checker PASS item: do not rewrite it; go to step 4. Otherwise read S/story-D.json only. Write S/spec-D.json (keys in tools/news/README.md). Rules: Ryan's plain voice, short; facts only from the story's posts; quotes copied exactly from the post text in story-D.json as "> text ~ [Name (@user) on X, Mon D, YYYY](post url)"; every number must appear in a cited post; never write "this week" or "last week"; no visible dates (Ryan's rule): no date or month-and-day (like "Nov 13") in the card kicker, card lines, X text or page prose (the only exception is the quote citation format above); no placeholders; no Landscape Specialists, Gavin, phone, email or address; the X text and the body must open with a hook line: a true, specific first line with a real number or payoff that the post delivers, with the source's qualifiers kept, and no clickbait or questions; X text <= 280 with no link that carries one exact phrase of the key claim from the post, in quote marks; keep the source's ~ or "about" on every number; 2 related_tips slugs from tips.py TIPS; a "What I haven't checked" section if you have not tested it yourself. The link reply is always written by the pipeline from the slug (Full story + sources: https://nextaibreakout.com/blog/SLUG/); never put a placeholder URL in the spec.
4. Run: PYTHONDONTWRITEBYTECODE=1 python3 tools/news/make_post.py --date D
5. Run: PYTHONDONTWRITEBYTECODE=1 python3 tools/news/publish.py --date D
   The money/plans/policy hold (G12) is OFF for now (config.json hold_money_policy false, Ryan 2026-11-14), so exit 20 should not happen; if it does (someone turned the hold back on), STOP silently: the draft and alert are already written.
   It builds, gates, pushes, deploys, checks the live URL, posts on @ryanpon (main post + card, then the link reply) and logs slot nab-news-D. If it prints STOP or exits non-zero, do NOT retry and do NOT post by hand: the reason is already in /workspace/shared/nab-relaunch/autopost-issues.md for Chief of Staff. If it fails only at the gate, you may fix the spec once (step 3-5); a second gate failure is final for the day. Exception: if today's spec came from a lesson, never edit it (its Quality Checker PASS is bound to the exact text by sha256, rule 23); a gate failure on a lesson is final for the day.
6. Done. No summary message. Every run (quiet, posted, held or failed) has already added one line to /workspace/shared/nab-relaunch/autopost-cost.jsonl; do not write to it yourself. Monthly totals: python3 /workspace/shared/nab-relaunch/news/cost_report.py --month YYYY-MM
